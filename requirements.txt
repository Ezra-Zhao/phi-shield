# The spaCy English models (NER for PERSON / LOCATION) are part of the
# pinned supply chain: exact release wheels with sha256 hashes, from
# the explosion/spacy-models 3.8.0 release (the line matching
# spacy==3.8.18 above).
#
# Do NOT replace these with `python -m spacy download ...`: that
# fetches whatever the then-current release is -- unpinned and
# unhashed (security-audit 2026-10-31, needs-validation item).
#
# en_core_web_lg is preferred at runtime; en_core_web_sm is the
# fallback.  Both are installed so a missing/broken preferred model
# cannot silently drop the service to a weaker backend.
en_core_web_lg @ https://github.com/explosion/spacy-models/releases/download/en_core_web_lg-3.8.0/en_core_web_lg-3.8.0-py3-none-any.whl#sha256=293e9547a655b25499198ab15a525b05b9407a75f10255e405e8c3854329ab63
en_core_web_sm @ https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.8.0/en_core_web_sm-3.8.0-py3-none-any.whl#sha256=1932429db727d4bff3deed6b34cfc05df17794f4a52eeb26cf8928f7c1a0fb85

# PHI_SHIELD_ALLOW_PATTERN_ONLY=1, with responses marked degraded
